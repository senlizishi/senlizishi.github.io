## 新增游戏「小猫咪插花」

女儿点子的需求：无分数无计时纯插花玩具，猫全程自主活动不需要交互。已确认参数：4-5 岁友好（判定超宽松）、插满给柔和反馈 + 重插按钮。

### 交付

- `flower.html` + `js/flower-game.js`（约 1200 行，全程序化绘制，零外部素材）
- `index.html` 加了卡片（`.card.flower` / `.thumb.flower`）
- `_flower-preview.html`：美术调试页（仿 `_mjpreview` 惯例保留），URL hash 支持 `#pose=sit&catx=420`，横竖屏自适应

### 设计要点（复用价值高）

- **9 个瓶口插槽**：`SLOT_ORDER = [0,-1,1,-2,2,-3,3,-4,4]` 从中间往两边交替，`t=k/4` 算 x 偏移/高度/倾斜/缩放，奇偶高度交错出前后层次。
- **花茎分层遮挡**：茎 depth 12 < 花瓶 20 < 花头 30，拖动中的花是 Container（depth 60），落地时拆成两个 Graphics 分别入层。
- **插满 = 一段旋律**：9 个槽位对应五声音阶 9 个音（C4→A5 上行），`Sound.plant(n)` 取 `NOTES[n]`，插满自然收束；满瓶再触发花摇 + 猫强制凑近闻 + 花瓣飘落。
- **猫状态机**：sleep/sit/walk/sniff 四姿态全部参数化重画（`CAT_POSE` 表），`catRoot`（位置/朝向镜像）与 `catInner`（呼吸 tween）双层分离避免 scale 冲突。
- **存档**：`localStorage['kitty-flower-v1']` 存 `{d:花材索引, r:半径}`，下次打开还是她插的那瓶。
- 落点判定 `overVase()`：瓶口左右各 2.6 倍半宽、上下各延伸一个花高，4 岁也能拖进去。

### 美术技术（Graphics 无旋转椭圆的解法）

- 花瓣 = `petalPoints(len, wid)` 二次贝塞尔采样点集 + `rotPts` 旋转，`fillPts/strokePts` 手写 beginPath/moveTo/lineTo（比 fillPoints/strokePoints 兼容性好）。
- 花瓶轮廓 = 8 个 profile 点 + **`Phaser.Curves.Spline` 平滑到 44 点再镜像**（直接折线连接会变多边形，这是踩过的坑）。
- 六种花 = 4 种形状（daisy/tulip/rose/pom）× 配色，`lighten/darken` 派生描边色。

### 无头验证流水线（重要，可复用）

本机 Chrome headless 直接截 Phaser 页面会得到空场景，坑有两个：

1. `--virtual-time-budget` 与 rAF 死循环冲突：页面要**主动停循环**（`game.loop.stop()`）。
2. **停循环后不会自动补最后一帧**——create 之后动态添加的对象（插入的花）不会出现在截图里。解法：stop 后手动 `game.loop.step(1000)` 强制渲染一帧再截图。调试时可加对照图形（`add.graphics` 红圆 + `add.circle` 蓝圆）区分"数据没插上"和"没渲染"。

命令模板：`chrome --headless=new --disable-gpu --screenshot=OUT --window-size=540,960 --virtual-time-budget=12000 file:///.../_flower-preview.html#pose=sit`。截图命令必须带 `timeout 75` 前缀，否则挂死会把 Bash 拖到 3 分钟超时。
